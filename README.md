# AgroSat - Global Solution FIAP 2026

Landing page e protótipo web em HTML, CSS e JavaScript puro para a solução AgroSat.

## Descrição do projeto

O AgroSat é uma estação de monitoramento agrícola embarcada em Arduino. A solução simula a integração entre dados locais de campo e conceitos de sensoriamento remoto usados por satélites como Sentinel-2 e Landsat.

O sistema acompanha temperatura, umidade do ar e luminosidade solar. Com esses dados, classifica riscos de seca, geada, calor extremo e umidade crítica.

## Objetivo da solução

- Democratizar dados agrícolas para pequenos produtores.
- Apoiar irrigação inteligente baseada em leituras locais.
- Emitir alertas precoces para reduzir perdas de safra.
- Conectar Arduino, edge computing e indústria espacial.

## Requisitos atendidos

- Menu de navegação funcional.
- Seis seções principais: problema, tecnologia, objetivos, público-alvo, benefícios e aplicação.
- Rodapé com integrantes e RMs.
- Imagens locais com atributo `alt`.
- Google Fonts, reset CSS, variáveis CSS e Flexbox.
- Slideshow com 3 imagens relacionadas ao tema.
- Formulário com validação contra campos vazios.
- Quiz dinâmico com 10 perguntas e resultado final.
- Três temas visuais de fundo.
- JavaScript puro, sem frameworks.
